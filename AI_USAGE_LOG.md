# AI Usage Log

ABTalks was developed using AI as a development assistant for architecture,
UI implementation, feature refinement, debugging, and documentation.

## Architecture & Development

- **Architecture:** AI helped structure the project using Next.js App Router,
  reusable components, CSS Modules, and mocked JSON data.
- **Routing:** AI assisted with the `/`, `/dashboard`, and dynamic
  `/day/[id]` routes and the day-state flow.
- **Components:** AI assisted in creating reusable UI components such as
  buttons, cards, badges, inputs, checkboxes, progress indicators, and
  shared navigation/footer components.
- **Mock Data:** AI helped structure student, challenge-day, progress,
  and proof-of-work data.

## Product & UX

- **Landing Page:** AI assisted with the 60-day product story,
  Build → Prove → Share flow, journey visualization, social proof,
  and responsive layout.
- **Dashboard:** AI assisted with streaks, progress, milestones,
  activity states, journals, and catch-up experience.
- **Challenge Days:** AI assisted with completed, missed, catch-up,
  current, and upcoming day experiences.
- **Day 12:** AI assisted with the learning-to-submission workflow,
  tutorial resources, Definition of Done, reflection, GitHub proof,
  LinkedIn proof, and submission validation.
- **Responsive Design:** AI assisted with the 390px mobile-first layout
  and desktop adaptation.
- **Theme & Typography:** AI assisted with the shared dark/light theme,
  Syne + Manrope typography, and light-mode readability improvements.

## Debugging

AI was also used to investigate and fix implementation issues including:

- Dynamic day routing and day-state resolution.
- Infinite state-update/rendering issues.
- Interactive Definition of Done checkboxes.
- Duplicate confirmation checkbox behavior.
- GitHub/LinkedIn proof validation.
- Responsive spacing and overflow issues.
- Light-theme text contrast.
- Footer implementation and icon compatibility.
- Production build and TypeScript/ESLint issues.

## Documentation

AI assisted with:

- README structure and project documentation.
- Product walkthrough documentation.
- Route documentation.
- AI prompt organization.
- Technical explanations and setup instructions.

## Transparency

The implementation was iteratively reviewed and tested during development.
AI-generated suggestions were inspected, modified, debugged, and integrated
as part of the development process rather than being accepted blindly.

Detailed prompts used during development are documented in `PROMPT.md`.
